# Autonomous Engineering Protocol

Setiap kali mengerjakan tugas, lalui 5 fase ini secara otomatis dan mandiri:

### FASE 1: DEVELOP &amp; CODE

- Terapkan fitur/perbaikan dengan kode yang bersih, modular, dan type-safe.

- Pastikan responsive pada tampilan mobile dan desktop.

### FASE 2: QA &amp; CODE QUALITY

- Jalankan linter dan format: `npm run lint`

- Bersihkan dead code, console.log yang tidak perlu, dan unused import.

### FASE 3: AUTOMATED TESTING

- Buat atau perbarui file unit test untuk fitur tersebut.

- Jalankan test: `npm test`

- Jika test gagal, perbaiki kode sampai lulus 100%.

### FASE 4: SECURITY &amp; VULNERABILITY CHECK

- Jalankan `npm audit`.

- Pastikan input pengguna ter-sanitasi dengan baik dan tidak ada secret/API key yang bocor.

### FASE 5: GIT COMMIT &amp; PULL REQUEST

- Jalankan perintah git:

  git add .

  git commit -m "feat: [Nama Fitur] - completed with QA, security audit &amp; tests"

  git push -u origin HEAD

  gh pr create --title "feat: [Nama Fitur]" --body "### Summary\n- Implemented [Nama Fitur]\n- Passed unit tests &amp; QA\n- Security audit clean\n\n*Automated PR generated by Orca Agent.*"
